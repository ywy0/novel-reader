# novel-reader

VS Code 小说阅读器:中文编码自动识别、只读、自动换行、整页翻页、书签、章节、书库。

## 安装

```bash
code --install-extension novel-reader-0.2.0.vsix
```

或:VS Code → 扩展面板 → `...` → 从 VSIX 安装。装完 **Reload Window**。

## 使用

1. 点击活动栏 📖「小说」打开侧边栏
2. 上半区**书库**:点「导入一本」或「导入文件夹」导入 txt(自动复制进书库目录,书库目录在 `.novel-reader` 配置文件旁)
3. 点击书籍开始阅读:自动识别 GBK / UTF-8 / UTF-16 编码,只读,长行自动换行

## 侧边栏

```
┌─────────────────────────┐
│ 书库   [导入一本] [导入文件夹] │
│ ▸ 斗破苍穹.txt            │
│ ▸ 凡人修仙传.txt           │
│─────────────────────────│
│    [书签]     [章节]      │  ← 两个按钮切换
│─────────────────────────│
│ 📍 上次读到 · 第 1234 行   │  ← 自动书签(停留≥5s)
│ 书签 · 第 500 行 文字预览  ✕ │
│ 书签 · 第 800 行 文字预览  ✕ │
└─────────────────────────┘
```

- **书签列表**:第一条永远是"上次读到"(阅读停留 ≥5 秒的行,自动记录);其余是手动书签
- **章节列表**:首次导入/打开时自动解析章节(第X章/节/回/卷、楔子、序章、尾声、番外等),打开面板自动高亮定位当前章节
- 书签和章节都在 **`<书库>/.novel-reader/<书名>.novel-reader`** 文件里,可移植、可编辑

## 操作

| 按键 | 功能 |
|---|---|
| `W` / `↑` / `PageUp` / `Shift+Space` | 上一页 |
| `S` / `↓` / `PageDown` / `Space` | 下一页 |
| 小说内**右键** → 添加书签 | 手动加书签(或 `Ctrl+Alt+B`) |
| `Alt+↓` / `Alt+↑` | 下一 / 上一书签 |
| 点击状态栏进度 | 打开书签面板 |
| 关闭再打开 | 自动回到上次位置 |

## 配置

| 配置项 | 默认 | 说明 |
|---|---|---|
| `novelReader.folder` | 空 | 书库文件夹路径 |
| `novelReader.pageLines` | 0 | 每次翻页行数,0 = 按视口整页翻 |
| `novelReader.encoding` | auto | 编码:auto / utf-8 / gbk / gb18030 / utf-16le |
| `novelReader.disableCodeFeatures` | true | 阅读模式总开关(自动换行+关代码功能),修改后重启生效 |

## 开发

```bash
npm install
npm run compile   # tsc 编译
npm run package   # 生成 .vsix
```

按 `F5` 打开 Extension Development Host 调试。
